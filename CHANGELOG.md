# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-27

### Added

- PostgreSQL connection dialog
- Host, port, database, username, and password inputs
- Password visibility toggle
- Optional remembering of non-password connection details
- Schema browser
- Table and view listing
- Table search/filter
- Database refresh button
- Table metadata panel
- Primary key detection
- Table owner detection
- Column count
- Row / feature count
- Geometry column detection
- Geometry/geography type detection
- Geometry type and SRID display
- Attribute preview for up to 50 rows
- Loading of spatial PostGIS tables into QGIS
- Loading of non-spatial PostgreSQL tables into QGIS
- Double-click table loading
- Scrollable interface for smaller displays
- Custom plugin icon support
- Initial public GitHub-ready release
